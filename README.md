# Viora UI

An elegant collection of motion-crafted React primitives, modern UI components, and Next.js templates designed for refined digital experiences.

Built with React, Next.js, Tailwind CSS, and Framer Motion.

---

## Overview

Viora UI is a design-focused component library emphasizing quality, reusability, and thoughtful motion. Every component is built as an independent, single-file primitive that can be dropped directly into modern React and Next.js applications without boilerplate or heavy dependencies.

### Key Highlights

- Motion Primitives: Fluid, physics-based micro-interactions and interactive widgets.
- Responsive by Design: Fully adaptive across mobile, tablet, and desktop viewports.
- Framework Agnostic: Optimized for Next.js App Router, but adaptable to Vite, Remix, and standard React setups.
- Accessible: Built following WAI-ARIA guidelines for keyboard and screen-reader accessibility.
